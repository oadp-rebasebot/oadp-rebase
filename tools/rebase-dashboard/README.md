# Rebase Dashboard

A React-based status dashboard for tracking OADP rebase progress across all downstream repositories. Deployed to GitHub Pages alongside the existing [Dependency Graph](../rebase-dag/).

**Live:** https://oadp-rebasebot.github.io/oadp-rebase/rebase-dashboard/

## Stack

| Layer | Technology | Why |
|-------|-----------|-----|
| Framework | [React 19](https://react.dev/) | Component model for rich interactive cards |
| Build | [Vite 6](https://vite.dev/) | Fast dev server + optimized static build |
| Language | TypeScript 5.8 | Type safety across data layer and components |
| Tests | [Vitest](https://vitest.dev/) | Vite-native test runner, same config |
| Confetti | [canvas-confetti](https://github.com/catdad/canvas-confetti) | Celebration when all repos are synced |

No graph library — the layout is a simple CSS column grid grouped by wave, with SVG connector lines drawn on hover. This replaced an earlier React Flow + dagre approach that was too visually cluttered for a hub-and-spoke dependency structure.

## Data

The dashboard consumes the same JSON files as the Dependency Graph page:

- `dag-metadata.json` — branch list and generation timestamp
- `dag-{branch}.json` — per-branch array of repo status objects with checks, dep syncs, CVE PRs

These files are generated by `rebase-status` in the [rebase-status-wiki workflow](../../.github/workflows/rebase-status-wiki.yaml) and copied into both `/rebase-dag/` and `/rebase-dashboard/` by [assemble-pages.sh](../assemble-pages.sh).

## Development

```bash
cd tools/rebase-dashboard

# Install dependencies
npm install

# Generate local test data (requires rebase-status binary)
cd ../rebase-status && go build -o /tmp/rebase-status .
cd ../rebase-dashboard
for branch in oadp-1.3 oadp-1.4 oadp-1.5 oadp-1.6; do
  /tmp/rebase-status -json "$branch" 2>/dev/null | \
    python3 -c "import json,sys; d=json.load(sys.stdin); print(json.dumps({'repos':d.get('repos',[]),'cve_prs':d.get('cve_prs',[])},indent=2))" \
    > "public/dag-${branch}.json"
done
cat > public/dag-metadata.json << 'EOF'
{"branches":["oadp-1.6","oadp-1.5","oadp-1.4","oadp-1.3"],"generated_at":"2026-01-01T00:00:00Z","default_branch":"oadp-1.6"}
EOF

# Start dev server
npm run dev

# Run tests
npm test

# Production build
npm run build    # outputs to dist/
```

## Project structure

```text
src/
  main.tsx              Entry point
  App.tsx               Top-level layout: header, summary bar, canvas, legend
  types.ts              TypeScript interfaces matching the JSON data contract
  dag-data.ts           Status classification and data transformation (shared with DAG page logic)
  dag-data.test.ts      Tests for dag-data.ts (23 tests)
  layout.ts             Dependency depth computation and relationship queries
  layout.test.ts        Tests for layout.ts (11 tests)
  hooks/
    useDAGData.ts       Fetch metadata + branch JSON, manage loading state
  components/
    Header.tsx          Title, branch selector, "Run rebase" link, help modal
    SummaryBar.tsx      Synced/in-progress/outdated counts, progress bar, confetti
    DAGCanvas.tsx       Column layout with repo cards and hover connector lines
    DetailPanel.tsx     Slide-out panel with full check table, deps, drifts, links
    Legend.tsx          Bottom status legend
  styles/
    theme.ts            Color tokens (GitHub dark palette)
    global.css          Root styles
```

## Deployment

Both CI workflows ([rebase-status-wiki](../../.github/workflows/rebase-status-wiki.yaml) and [prow-audit-pages](../../.github/workflows/prow-audit-pages.yaml)) build the dashboard and deploy it to GitHub Pages:

1. `actions/setup-node` + `npm ci` + `npm run build` → produces `dist/`
2. `assemble-pages.sh` copies `dist/*` to `_site/rebase-dashboard/`
3. `actions/deploy-pages` publishes `_site/` to GitHub Pages
